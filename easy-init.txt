FANTASY WORLD CUP - INICIO RAPIDO (ARQUITECTURA REESTRUCTURADA)

1. Requisitos:
- Docker y Docker Compose.
- Go (Instalado automaticamente en ~/go_dist).

2. Iniciar Proyecto Completo (Infraestructura + Backend):
Ejecuta el script de automatizacion integral:
./start-project.sh

3. Detener Todo:
docker compose down -v && fuser -k 8080/tcp

4. Datos de Conexion:
- Host: 127.0.0.1
- Puerto DB (Postgres): 5433
- Puerto Cache (Redis): 6379
- Puerto API (Go): 8080

Estructura:
/database  -> Scripts SQL, CSV y Documentacion DB.
/cmd       -> Punto de entrada del servidor.
/internal  -> Logica de negocio (Repository, Service, Handler).
/pkg       -> Utilidades compartidas.
